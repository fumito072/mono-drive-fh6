# Mono Drive — local FH6 driving experiments

単眼のゲーム映像と Forza Data Out を使い、ローカルの認識・経路計画・仮想 Xbox コントローラーで走行を試す Python プロジェクトです。人間の録画を取り込み、候補モデルの学習、独立した検証、実走試験、問題発生時の切り戻しを行います。

## 現状

研究・実験段階です。左車線の中央を約60km/hで安定して走る目標は未達で、誤認識・逸脱・停止が発生します。実車向けではありません。ゲーム内の自動運転は使用せず、外部からアナログ入力を送ります。

## 公開範囲

このリポジトリはソースコード、テスト、設定のひな形を公開しています。録画、操作ログ、Googleアカウント情報、認証情報、学習済みの重み、ゲーム画面・UI画像は含みません。設定のDrive連携、コース移動、古いデータの自動削除は初期状態では無効です。

モデルの重みとゲームごとの画面校正データは別途用意してください。この公開コピーだけでは即座にゲームを自動操作できません。依存するモデルやライブラリの利用条件はそれぞれ確認してください。元プロジェクトのライセンス情報は [docs/LICENSES.md](docs/LICENSES.md) にあります。コード全体に対する新しい再配布ライセンスは追加していません。

## 構成

- `mono_drive/`: 認識、経路計画、交通・車線判定、入力、記録、候補モデルの検証・切り戻し
- `tools/`: 人間の録画の同期検査・取り込み、学習、評価、走行ログの診断
- `configs/`: 個人情報を除いた設定例
- `tests/`: 単体テスト。非公開のゲーム画像が必要なテストはスキップします。

## セットアップ

Windows、Python 3.12（64bit）を想定します。

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-forza.txt
```

GPU学習と認識の環境は別に作成し、利用するGPUに対応したPyTorchを導入してから必要な認識モデルの依存ライブラリをインストールします。GPUのドライバー、仮想コントローラーのドライバー、モデルの重みは同梱しません。

```powershell
py -3.12 -m venv .train-venv
.\.train-venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.train-venv\Scripts\python.exe -m unittest discover -s tests -q
```

ゲームのData Out、表示領域、車種、コントローラーの設定を合わせ、モデルと画面校正を用意した後に操作を開始してください。`mono_drive.forza_control hold` で専用停止を要求できます。停止要求ファイルは自動で解除しません。

## 学習と実走評価

人間の記録は動画とData Outの時刻対応を検査し、学習用と検証用の時間帯を分離します。記録上の誤差、暗さやぼけによる悪化、録画ごとの性能を確認した候補だけを実走試験へ進めます。実走評価では速度、制動、道路上の位置の推定、逸脱・復帰を記録します。推定結果は実際の車線位置の正解データではありません。

設定を変更する前に、ローカルの録画・校正・設定をバックアップしてください。
