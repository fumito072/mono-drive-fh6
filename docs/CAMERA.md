# カメラの合わせ方

モデルは決まった 1 種類のカメラ(下の「基準の視点」)の絵しか見ていません。設定の `camera` に自分のカメラの値を書くと、絵をその視点へ
作り直してからモデルに入れ、答えの距離も自分の車の m に直します。値がずれていると、道の予想が横へずれたり、距離を読み違えたりします。

## 1. 設定の項目(`configs/*.json` の `camera`)

| 項目 | 意味 | 決め方 |
|---|---|---|
| `width`, `height` | 絵の大きさ [画素] | 動画の大きさ。違う大きさの絵が来ても比で直す |
| `hfov_deg` または `vfov_deg` | 横(縦)の画角 [deg] | カメラの仕様、または下の「較正」。`fx`, `fy`(焦点距離 [画素])で書いてもよい |
| `cx`, `cy` | 光軸の画素 | 書かなければ絵の真ん中 |
| `pitch_deg` | 下向きの角度(下向きが正) | 水準器のアプリで測る → 格子で直す |
| `roll_deg` | 傾き(絵が時計回りに回って見えるとき負) | 水平な物で合わせる。たいてい 0 |
| `yaw_deg` | 左右の向き(右向きが正) | 車の正面に合わせて付けたなら 0 |
| `height_m` | 地面からのカメラの高さ [m] | 巻き尺で測る(平らな所で) |
| `fwd_m` | 車の基準点からカメラまでの前の距離 [m] | 基準点は後車軸の中心がよい(ハンドルの計算が合う) |
| `right_m` | 車の中心線からカメラまでの右の距離 [m] | 真ん中に付けたなら 0 |
| `crop_top` | 上から使わない行 | 画面の録画でウィンドウのタイトルバーが入るときなど |
| `model`, `dist` | 歪み | `pinhole`: `[k1, k2, p1, p2, k3]`(OpenCV)/ `fisheye`: `[k1, k2, k3, k4]`。歪みの少ないカメラなら `null` |
| `hood` | ボンネット・ダッシュボードの上端 `[[u, v], ...]` | 絵を画像ビューアで開き、車体の縁の点の座標を左から順に書く。これより下は使わない |

## 2. 基準の視点(学習時のカメラ)

| | 値 |
|---|---|
| 絵 | 576x360(モデルに入るのは上の 0〜240 行 = 地平線の上 24° 〜 下 15.5°) |
| 画角 | 縦 58.2°・横 約 83° |
| 向き | 5° 下向き・ロール -0.25° |
| 位置 | 高さ 1.1m・車の中心より 0.35m 左・基準点より 0.2m 後ろ(運転席の目の位置) |

**向いているカメラ**: 横の画角 84° 以上(広角)、前を向いて少し下向き、ボンネットやダッシュボードが絵の下 1/3 より上に来ない所。
画角が狭いと、モデルの見る範囲の左右(または上下)が足りず、端の画素を引き伸ばして埋めます(当たりが落ちる)。
`tools/check_camera.py` と `python -m mono_drive` が「埋まっている割合」を出します。

## 3. 確かめる・直す

```bash
.venv/bin/python tools/check_camera.py --config configs/my_car.json --input my_video.mp4 --frame 100
```

`camera_check.jpg` の左に、元の絵の上へ平らな地面の格子(前 5・10・15・20・30・40m、右 ±1.75・±3.5m)・地平線(水色)・モデルが
見る範囲(黄色の枠)を、右にモデルが見る絵を描きます。平らでまっすぐな道の絵で:

1. **地平線**(水色の線)が遠くの道の消える高さに来るまで `pitch_deg` を直す(上にずれていれば下向きを大きく)
2. **車線**(普通の道は 1 車線 3.5m 前後)や道の端が ±1.75m・±3.5m の線に沿うまで `height_m`(と画角)を直す。
   遠くほど線が開いていくなら高さを低く、すぼまるなら高くする
3. 絵が傾いていれば `roll_deg`、道の消える点が左右にずれていれば `yaw_deg`

## 4. 画角と歪みを較正する(より正確に)

チェッカーボード(市松模様)をいろいろな向きで 20 枚ほど撮り、OpenCV の `cv2.calibrateCamera`(魚眼は `cv2.fisheye.calibrate`)で
`fx`, `fy`, `cx`, `cy`, `dist` を求めて設定に書きます(OpenCV の「Camera Calibration」の手順)。歪みの大きい広角カメラでは特に効きます。

## 5. 小さな車両・ロボット

カメラが低い(例 0.3〜0.5m)と、距離の倍率 k = 高さ / 1.1 が小さくなり、モデルは「縮めた世界」を見ることになります
(高さ 0.3m のカメラで見た幅 1.5m の通路は、モデルには幅 5.5m の道に見える)。道らしく見える所ならそのまま動きます。
速さ・距離の規則は `planner` で小さくしてください(`configs/small_robot_template.json`)。
