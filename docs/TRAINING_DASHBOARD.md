# ローカル学習モニター

学習処理を動かしたまま、進捗と検証結果をブラウザーで確認できます。
プロジェクトのフォルダーで実行します。

```powershell
.\.train-venv\Scripts\python.exe -m mono_drive.training_dashboard --background --open
```

表示先は `http://127.0.0.1:8765/` です。ウィンドウを閉じても学習と表示用サーバーは継続します。
同じコマンドをもう一度実行すると、起動済みサーバーを使います。
別のポートを使う場合は `--port 8766` のように指定してください。

## 表示内容

- 主な時系列学習の完了周数、途中保存時刻、再開回数
- 検証用データで測った全体・旋回時・操作変化の誤差
- 単画像モデルと時系列モデルの比較（最初の8周の時系列モデルは初期調整中のため表示しません）
- 高密度の動画学習、操作量がない動画の補助学習、経路モデル、ローカル映像監視の状態
- 学習・検証・最終テストに分けたデータ数
- GPU使用率・メモリー・温度、およびゲーム走行・実走評価の状態

ログを1秒ごと、GPUを15秒ごとに確認します。検証誤差のグラフは学習の各周が終わったときに更新されます。
周数の上限は完了時刻の予測ではありません。検証が改善しなければ早期に終了します。

学習状態は `out/deep-learning-state.json` から対象モデルを決め、その `training-progress.json` と `report.json`、
`out/deep-forecast.log` と `out/deep-resume.log` を読みます。
他の処理は既存の状態ファイルを参照し、画面を開くために学習を起動・停止しません。
ログが未作成なら未確認と表示し、古い走行速度を現在の速度として表示しません。

サーバーはこのPCのループバックアドレスだけで待ち受けます。外部配信やクラウド転送をせず、
学習の開始・停止・採用を行うAPIもありません。「表示の更新を一時停止」は画面の更新だけを止めます。
GPU情報の取得には `nvidia-smi`、実行プロセスの確認には `psutil`（導入済みの場合）を使います。

## 確認

```powershell
.\.train-venv\Scripts\python.exe -m unittest tests.test_training_dashboard -v
```

初期調整中のグラフ除外、古い速度の非表示、明示停止の表示、モデル読み取り範囲、
書き込み途中のログ、読み取り専用HTTPの動作を確認します。
